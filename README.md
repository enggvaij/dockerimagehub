# Setup the project 
1. create the directory or new folder in desired location e.g d:/code/dockerimage
2. Open the visual studio code in this folder
3. Create the files listed below under the folder d:/code/dockerimage
  1. app.py
  2. test_app.py
  3. requirements.txt
  4. DockerFile
  5. .gitignore
